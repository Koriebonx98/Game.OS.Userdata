- Accounts: (Online/Offline)
Game OS has its own account system to sync playtime, achivements, friends list, wishlist, libaray, and other bits of data, User Data is encrtyped and stored via a private repo on github until a change is needed..
Game OS Also offers local accounts via the Launcher App, this ensures users who dont have internet can still enjoy features and a connsole like expreince on pc

- Scanner:
Scanner will auto find...

Games/SetUp Files, Archives & Repacks and combine per platform.
This is usful as Pc Players Want Ease to download/play Games, Roms or Media without having to dig via folders or multiple launchers... this gives pc usrese a mroe consonle expeince 
It Searches Folders "<Root>/Games/$GameFolderName/...$ExeFile" for games, it also searches default launcher folders like Steam, Epic, GoG and many more.. 
if a game is in multiple drives users are able to decided in Game Info Page what Drive & Exe to use.. this then makes game managment easier and more simple

Roms, use "<Root>/Roms/$PlatformName/Games/$RomName" else "<Root>/Roms/$PlatformName/Games/$GameName/$RomName" 
Examples of "$platformNames"
"Nintendo - Switch" "Sony - PlayStation 2" "Microsoft - Xbox 360"  

Media, does same as "Games" and "Roms" but searches "<Root>/Media/$MediaType/" 
"$MediaTypes" 
"Movies" = "Movies/$MovieName/$MediaFile" else "Movies/$CollectionName/$MediaFile" or "Movies/$MediaFile" 
"Tv Shows" = "Tv Shows/$ShowName/$Series/$Episode/$MediaFile" else "Tv Shows/$ShowName/$MediaFiles" such as "Show Name.S01.E01.EpName.Mp4" 
"Music" = "Music/$ArtistName/$Album/$Songs" else "Music/$ArtistName/$Songs" 

This makes setting up Games/Roms/Media 100x easier and displays in one place, this is what consoles players are use to and what pc players wish was the default!

- Cloud Saves:

"Game OS" uses ludusavi x custom backup tool to backup PC Games and Roms, most users who use ludusavi knows that its painful to set up manually and most people "Sync" the whole emu per game
issue is then that the user is using more stoargge than needed.. 

What we done is use our own Games DB that includes "$TitleID" or "$AppID" and in emulator settings a "Save" path location... this then helps to identify Games to Back Up 

issue/bug = while setting this up one of the bugs i came across was some games/Rom had Multiple Regional "$TitleID" this would then say "No Save Found" (Xenia Emu) when user tried to "Back UP" 
However if user already had a save in "GameOS.exe/Data/$profile/GameSaves/$PlatformName/$TitlteID" then they could "Restore" succesfully but not back up...

Fix: I rewrote the code and got Game OS to combine all Games with same "$GameName" but more than 1x "$TitleID" in Game Info Page (Per PLatform), then when "Back UP" it makes a folder per "$TitleID" and copy save
into Each "$TitleID" ... this then made cloud Saves not only work fully with "Game OS" but resolved a future solution as now game saves will work regardless of region 

for example "Skate 3" has "USA" "JAP" "Uk" and "EU" on xbox 360... with this fix itll make 4x "$TitleID" inside of "GameSaves/Skate 3/$TitleID" so no matter what region it will be playable
